## Review Focus

1. Profile files already exist with different content: refuse replacement before installing either profile; do not overwrite operator configuration.
2. Profile-v2 parses but inherited/project settings alter the effective model or effort: inspect actual live seat configuration, rather than treating TOML parsing as proof.
3. Multiple seats share a checkout: keep role-specific text out of shared `AGENTS.md`, serialize Git/shared-contract edits, and preserve existing dirty files.
4. Partial startup or lost authentication: report exactly which seats are not ready; do not clear attention or claim success without runtime evidence.
5. Quota exhaustion or same-account PR review: preserve the explicit quota stop and GitHub self-approval distinction in startup context and demonstrate the seats understand those limits.

### Task 1: Provision dedicated Codex profiles without overwriting settings

**Files:** Create `rig/setup.py`, both `rig/runtime/*.config.toml` files, and `tests/test_rig_setup.py`.

**Interfaces:**
- Consumes: repo-owned profile-v2 TOML files and the actual Codex home (`CODEX_HOME` if configured, otherwise the operator's `.codex` directory).
- Produces: `install_profiles(source: Path, target: Path) -> list[Path]`, with both files validated and all conflicts checked before any destination mutation.
- Raises: `ValueError` for conflicting, malformed, or symlinked destination profiles. Identical files are no-ops. Never writes `target/config.toml`.

- [ ] Write the following behavioral tests before implementing the installer. Import the module with `importlib.util.spec_from_file_location` so `rig/` need not become an application package. Use pytest's `tmp_path` and `pytest.raises`.

```python
def test_preserves_defaults_and_is_idempotent(tmp_path):
    source = tmp_path / 'source'
    target = tmp_path / 'codex'
    source.mkdir()
    target.mkdir()
    for name in ('fugu-rig-high', 'fugu-rig-medium'):
        (source / f'{name}.config.toml').write_text('sandbox_mode = "workspace-write"\n')
    defaults = target / 'config.toml'
    defaults.write_text('model = "operator-choice"\n')
    module.install_profiles(source, target)
    installed = target / 'fugu-rig-high.config.toml'
    first = installed.stat().st_mtime_ns
    module.install_profiles(source, target)
    assert installed.stat().st_mtime_ns == first
    assert defaults.read_text() == 'model = "operator-choice"\n'

def test_conflict_is_detected_before_installing_any_file(tmp_path):
    source = tmp_path / 'source'
    target = tmp_path / 'codex'
    source.mkdir()
    target.mkdir()
    for name in ('fugu-rig-high', 'fugu-rig-medium'):
        (source / f'{name}.config.toml').write_text('sandbox_mode = "workspace-write"\n')
    conflict = target / 'fugu-rig-medium.config.toml'
    conflict.write_text('model = "existing-choice"\n')
    with pytest.raises(ValueError):
        module.install_profiles(source, target)
    assert not (target / 'fugu-rig-high.config.toml').exists()
    assert conflict.read_text() == 'model = "existing-choice"\n'

def test_malformed_source_writes_nothing(tmp_path):
    source = tmp_path / 'source'
    target = tmp_path / 'codex'
    source.mkdir()
    (source / 'fugu-rig-high.config.toml').write_text('sandbox_mode = "workspace-write"\n')
    (source / 'fugu-rig-medium.config.toml').write_text('invalid = [\n')
    with pytest.raises(ValueError):
        module.install_profiles(source, target)
    assert not target.exists()

def test_symlinked_destination_is_not_followed(tmp_path):
    source = tmp_path / 'source'
    target = tmp_path / 'codex'
    source.mkdir()
    target.mkdir()
    for name in ('fugu-rig-high', 'fugu-rig-medium'):
        (source / f'{name}.config.toml').write_text('sandbox_mode = "workspace-write"\n')
    outside = tmp_path / 'outside'
    outside.write_text('preserve me')
    (target / 'fugu-rig-high.config.toml').symlink_to(outside)
    with pytest.raises(ValueError):
        module.install_profiles(source, target)
    assert outside.read_text() == 'preserve me'
    assert not (target / 'fugu-rig-medium.config.toml').exists()
```

## Self-review and execution recommendation

The three tasks cover profile configuration, the approved topology and every
operating rule, then separate runtime proof and handoff. Installer checks own
Review Focus 1; actual session inspection owns 2; shared guidance/state checks
own 3; startup proof and partial-start reporting own 4; culture and orientation
answers own 5. User stories US-1 through US-14 are represented by those tasks.

Recommended execution: **Native**. The work has only three dependent tasks,
primarily configuration and guidance; one implementer can keep paths and
runtime assumptions consistent, followed by a fresh independent whole-change
review. Subagent-driven execution remains an option if the operator prefers
independent review at each task boundary.
