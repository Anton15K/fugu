# Help Docs

One place to search the how-to pages that ship with your tooling. Pages
are bundled at install time; the skill is fully offline.

## Tools

- `list_docs` — list every bundled documentation page
- `search_docs` — find pages and sections matching a query

No network access, no filesystem access outside the docs directory.
