# Fugu attack corpus

Ten labeled extension samples for the eval harness: 6 malicious, 4 benign.
Every sample directory carries a `manifest.json` describing what a correct
scanner should find. The corpus is the ground truth for measured
precision/recall of stages S0 (concealment) and S1 (static scan).

## Manifest schema

Each `corpus/<sample>/manifest.json` is a JSON object:

| field               | type       | meaning                                                       |
| ------------------- | ---------- | ------------------------------------------------------------- |
| `name`              | string     | Sample id, matches the directory name.                         |
| `kind`              | string     | `"malicious"` or `"benign"`.                                  |
| `expected_owasp_ids`| string[]   | OWASP ids the pipeline is expected to emit for this sample. Empty for benign. |
| `description`       | string     | One-paragraph human explanation of the attack (or the absence of one). |

Loading rules for a generic harness:

1. Enumerate `corpus/*/manifest.json`.
2. For each, run the stage(s) under test against the sample directory.
3. `malicious`: union of `owasp_ids` across all findings must be a superset of `expected_owasp_ids` (each expected id must be covered by at least one finding).
4. `benign`: the stage must produce **zero** findings, modulo the documented false positives below.

## Regenerating sample 02

`02-unicode-smuggled-skill/SKILL.md` contains invisible codepoints; it is
generated by `corpus/build.py` and **committed alongside it** so fresh
clones work offline. To regenerate:

```bash
uv run --no-sync python corpus/build.py
```

The script asserts a decode round-trip before writing.

## Documented false positives (benign samples)

Known, intentional FP sources — a harness asserting "zero findings" must
subtract these:

- **`06-rugpull-pair/v1`** is *inside a malicious sample dir* and is clean;
  only `v2/server.py` should flag (injection phrase, MCP03/LLM01).
- **`09-clean-installer`**: `install -m 0755 ...` uses the word `install`
  but contains no curl/wget/subprocess — the `setup_py_subprocess` /
  `install_script_fetch` rules do not fire on it (verified by tests).
- The static stage's `sensitive_path_access` rule treats `~/.local/bin`
  (in 09) as NOT sensitive — only `.ssh/.aws/.netrc//etc/passwd` are.
- S0's homoglyph check is **opt-in** (`ConcealmentStage(detect_homoglyphs=True)`)
  and disabled by default; it can FP on legit multi-language prose.

## Verifying the corpus

```bash
uv run --no-sync pytest tests/test_concealment.py tests/test_static_scan.py -q
```

The tests iterate every manifest and assert the coverage rules above.
